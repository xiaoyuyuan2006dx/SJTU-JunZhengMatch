# 䇹政盲审导师匹配

上传学生课题，匹配评审导师，维护公开教师库，并导出原格式 CSV / Excel。

# 使用

## Windows（源码运行与 EXE）

在 [Releases](https://github.com/xiaoyuyuan2006dx/SJTU-JunZhengMatch/releases/latest) 选择：

- **portable.zip**：解压后双击 `JunZhengMatch.exe`，在浏览器操作，无需安装 Python。
- **setup.msi**：安装时选择程序和数据位置，使用桌面或开始菜单快捷方式打开独立窗口。缺少 WebView2 时安装程序会联网补装。

默认数据位于 `%USERPROFILE%\JunZhenMatch`（C盘用户目录下），不存在时自动创建。浏览器版首次启动会提示位置，两版均可在“偏好设置”中修改、迁移、备份恢复。教师库、导出、日志保存在此处；原始上传默认不保留，可在偏好设置开启。升级或卸载保留数据。

两版使用同一数据目录时共用一个后台。**关闭某个标签页或窗口只关闭当前界面，不影响另一个界面。** 右上角“退出程序”才停止共享服务；多个界面在线时会提示确认，匹配或爬取期间需等待任务结束。

源码运行（Python 3.12）：

```bash
python -m pip install -r packaging/requirements.txt
python packaging/launcher.py
```

Windows 独立窗口另安装 `packaging/requirements-desktop.txt`，运行 `python packaging/launcher.py --desktop`。编译 EXE：

```bash
python -m pip install -r packaging/requirements-dev.txt
python tools/build_version.py --version v1.1.0
pyinstaller --clean --noconfirm packaging/JunZhengMatch.spec
```

详细使用见 [WINDOWS.md](WINDOWS.md)，自行上传和发布见 [RELEASING.md](RELEASING.md)。

## Docker

```bash
JZ_PASSWORD='替换为至少12字符的密码' docker compose up -d --build
```

打开 `http://127.0.0.1:8765`，登录用户名可任意填写。数据持久化至 `/data`，路径由挂载设置管理。也可下载对应版本的 `docker-amd64.tar.gz`，使用 `docker load -i 文件名` 导入。默认仅暴露本机端口；非本机监听必须设置至少12字符密码。

# 输入

页面可下载单行表头的空白 XLSX / CSV 模板，以及仅含张三、李四、王五等虚构信息的示例模板。

| 列名 | 要求 |
|---|---|
| 序号 | 保留列名；空值自动编号 |
| 课题类别 | 选填，原样保留 |
| 学生姓名 | 必填 |
| 学生学号 | 选填，建议文本格式 |
| 课题中文 | 必填，也接受“课题” |
| 导师姓名 | 必填，用于回避指导老师 |
| 导师院系 | 选填，也接受“导师学院” |

支持单横行名单和原有每人三行的合并表，仅读第一张工作表。支持 `.xlsx` / `.csv`；上限10000行、256列、200万个矩形单元格，XLSX解压上限100MB。公式需有已保存的计算结果，不执行公式或宏。

课题类别沿用五类：人文社科类、信息技术类、机械控制自动化类、生农医药类、能源化工材料类。

# 输出

- **CSV**：每人一行；前七列学生信息，随后各评审的姓名、学院、职称、电话、邮箱、研究方向、匹配方向、相近程度。UTF-8 BOM，不含人工核验列。
- **XLSX**：原有十三列合并单元格表，每位评审一行；首个单元格使用可填写的任务说明，负责人和日期留作模板，不沿用真实成品信息。

两种导出均保留完整字段，同时存入数据目录的 `exports`。预览学号缩为 `52x…`，匹配方向显示前四字，不影响导出。相近程度是推荐分，不代表正确率。

# 参数

每次匹配可单独修改参数；“偏好设置”可保存后续任务的默认值。

| 页面参数 / 脚本参数 | 默认 | 说明 |
|---|---|---|
| 每人评审数 / `--pick` | 3 | 每位学生的评审位置数 |
| 候选池 / `--pool` | 20 | 参与选取的候选数，不小于评审数 |
| 教师使用上限 / `--max-teacher-uses` | **2** | 同一教师在**本次选中的全部学生**中最多出现几次；按规范化姓名统一计数，翻页不重置，下次任务重新计数 |
| 选取策略 / `--strategy` | top | top取排序靠前者；weighted在候选中加权抽样 |
| 随机种子 / `--seed` | 42 | 控制加权抽样复现 |
| 最低分 / `--min-score` | 0.05 | 严格筛选的最低推荐分 |
| 相对阈值 / `--relative-score` | 0.4 | 相对最高候选分的保留比例 |
| 严格模式 / `--strict` | 关闭 | 开启后仅保留通过阈值者；关闭可补充较弱候选 |
| 允许未知职称 / `--allow-unknown-title` | 关闭 | 开启可纳入职称不明的教师 |

同一学生不重复，回避指导老师和明确正高记录。两种模式均遵守教师使用上限；若可用教师不足，会留空并提示原因，不会超额补齐。上限1适合完全不复用；提高上限可缓解候选不足，但不保证相关性。

页面支持全部学生、序号范围、单个序号和姓名筛选。启动支持 `--port 8080`、`--data-dir 路径`、`--no-open`（前台服务）；`JZ_DATA_DIR` 可指定数据目录。脚本接口：`PYTHONPATH=src python -m junzheng_match.sjtu_match_reviewers --help`。

# 数据库

自带 **737 条 SJTU 教师记录，均来源于网络公开资料**，包含已有研究方向和公开联系方式，下载即可使用。首次运行复制为可维护的教师库，更新程序不覆盖已有库。

“数据库维护”支持检索、新增、编辑、删除、院系筛选及增量导入。保留基本信息爬取、研究方向增量、主页补扫院系和网络搜索补院系四个接口及参数。写入前自动备份，最多保留20份；爬取依赖公开站点可用性。

“偏好设置”可迁移到空目录，或明确选择使用目标目录已有库；不会直接覆盖目标库，原目录保留。旧版数据可将旧数据文件夹作为“使用目标已有库”的位置，或通过备份恢复导入数据库。Docker路径由挂载设置决定。

发布包不含学生原表、上传记录、运行日志和凭据。匹配会话在内存中隔离，闲置24小时失效，重启清空。
