# 䇹政盲审导师匹配

上传学生课题，匹配评审导师，维护公开教师库，并导出原格式 CSV / Excel。

[下载最新版（Latest Release）](https://github.com/xiaoyuyuan2006dx/SJTU-JunZhengMatch/releases/latest)

# 使用

## Windows（源码运行与 EXE）

在 [Releases](https://github.com/xiaoyuyuan2006dx/SJTU-JunZhengMatch/releases/latest) 选择：

- **portable.zip**：解压后双击 `JunZhengMatch.exe`，在浏览器操作，无需安装 Python。
- **setup.msi**：安装后从桌面、开始菜单或安装目录的 EXE 打开独立窗口，默认最大化。

发现旧版本时会询问是否升级；相同版本可修复或卸载。安装包比已装版本旧时，可进入已装版本的维护页面。操作前先点击程序右上角的退出图案停止后台。

程序和数据请选择分开的文件夹。安装通常约10–30秒，界面显示实际步骤、进度条及独立跳动的粒子；粒子是等待反馈，不代表安装百分比。首次启动仅在缺少组件时准备运行环境，通常约1–3分钟；已有环境不会显示额外安装窗口。安装失败可查看日志。

默认数据位于 `%USERPROFILE%\JunZhenMatch`（C盘用户目录下），不存在时自动创建。浏览器版首次启动会提示位置，两版均可在“偏好设置”中修改存储位置及导入导出数据。教师库、导出、日志保存在此处；不保留上传原表。升级或卸载保留数据。卸载完成页显示实际数据路径，可点击“打开数据文件夹”；确认不再需要后，可自行删除数据目录。

两版使用同一数据目录时共用一个后台。**关闭某个标签页或窗口只关闭当前界面，不影响另一个界面。** 右上角“退出程序”才停止共享服务；多个界面在线时会提示确认，匹配或爬取期间需等待任务结束。

源码运行（Python 3.12）：

```bash
python -m pip install -r packaging/requirements.txt
python packaging/launcher.py
```

Windows 独立窗口另安装 `packaging/requirements-desktop.txt`，运行 `python packaging/launcher.py --desktop`。编译 EXE：

```bash
python -m pip install -r packaging/requirements-dev.txt
python tools/build_version.py --version v1.2.3
pyinstaller --clean --noconfirm packaging/JunZhengMatch.spec
```

详细使用见 [WINDOWS.md](WINDOWS.md)，自行上传和发布见 [RELEASING.md](RELEASING.md)。

MSI 内含 WebView2 完整离线组件，缺少时本地安装，已有时跳过。升级、修复或卸载需要授权时，点击 Windows 提示中的“是”即可。

## Docker

```bash
JZ_PASSWORD='替换为至少12字符的密码' docker compose up -d --build
```

打开 `http://127.0.0.1:8765`，登录用户名可任意填写。数据持久化至 `/data`，路径由挂载设置管理。也可下载对应版本的 `docker-amd64.tar.gz`，使用 `docker load -i 文件名` 导入。默认仅暴露本机端口；非本机监听必须设置至少12字符密码。

# 输入

页面可下载单行表头的空白 XLSX / CSV 模板，以及仅含张三、李四、王五等虚构信息的示例模板。

| 列名 | 要求 |
|---|---|
| 序号 | 保留列名；空值自动编号 |
| 课题类别 | 选填，原样保留 |
| 学生姓名 | 必填 |
| 学生学号 | 选填，建议文本格式 |
| 课题中文 | 必填，也接受“课题” |
| 导师姓名 | 必填，用于回避指导老师 |
| 导师院系 | 选填，也接受“导师学院” |

支持单横行名单和原有每人三行的合并表，仅读第一张工作表。支持 `.xlsx` / `.csv`；上限10000行、256列、200万个矩形单元格，XLSX解压上限100MB。公式需有已保存的计算结果，不执行公式或宏。

课题类别沿用五类：人文社科类、信息技术类、机械控制自动化类、生农医药类、能源化工材料类。

# 输出

- **CSV**：每人一行；前七列学生信息，随后各评审的姓名、学院、职称、电话、邮箱、研究方向、匹配方向、相近程度。UTF-8 BOM，不含人工核验列。
- **XLSX**：原有十三列合并单元格表，每位评审一行；首个单元格使用可填写的任务说明，负责人和日期留作模板，不沿用真实成品信息。

两种导出均保留完整字段，同时存入数据目录的 `exports`。预览学号缩为 `52x…`，匹配方向显示前四字，不影响导出。相近程度是推荐分，不代表正确率。

# 参数

每次匹配可单独修改参数；“偏好设置”可保存后续任务的默认值。

| 页面参数 / 脚本参数 | 默认 | 说明 |
|---|---|---|
| 每人评审数 / `--pick` | 3 | 每位学生的评审位置数 |
| 候选池 / `--pool` | 20 | 参与选取的候选数，不小于评审数 |
| 教师使用上限 / `--max-teacher-uses` | **2** | 同一教师在**本次选中的全部学生**中最多出现几次；按规范化姓名统一计数，翻页不重置，下次任务重新计数 |
| 选取策略 / `--strategy` | top | top取排序靠前者；weighted在候选中加权抽样 |
| 随机种子 / `--seed` | 42 | 控制加权抽样复现 |
| 最低分 / `--min-score` | 0.05 | 严格筛选的最低推荐分 |
| 相对阈值 / `--relative-score` | 0.4 | 相对最高候选分的保留比例 |
| 严格模式 / `--strict` | 关闭 | 开启后仅保留通过阈值者；关闭可补充较弱候选 |
| 允许未知职称 / `--allow-unknown-title` | 关闭 | 开启可纳入职称不明的教师 |

同一学生不重复，回避指导老师和明确正高记录。两种模式均遵守教师使用上限；若可用教师不足，会留空并提示原因，不会超额补齐。上限1适合完全不复用；提高上限可缓解候选不足，但不保证相关性。

匹配结果右上角的箭头可收起或展开预览，收起后仍可导出，结果不会丢失。页面支持全部学生、序号范围、单个序号和姓名筛选。启动支持 `--port 8080`、`--data-dir 路径`、`--no-open`（前台服务）；`JZ_DATA_DIR` 可指定数据目录。脚本接口：`PYTHONPATH=src python -m junzheng_match.sjtu_match_reviewers --help`。

# 数据库

自带 **737 条 SJTU 教师记录，均来源于网络公开资料**，包含已有研究方向和公开联系方式，下载即可使用。首次运行复制为可维护的教师库，更新程序不覆盖已有库。

“数据库维护”支持检索、新增、编辑、删除、院系筛选及增量导入。保留基本信息爬取、研究方向增量、主页补扫院系和网络搜索补院系四个接口及参数。写入前自动备份，最多保留20份；爬取依赖公开站点可用性。

“偏好设置”选择新位置时，空目录会迁移现有数据；已有兼容教师库则提示确认后使用目标库，原目录保留。Docker路径由挂载设置决定。

发布包不含学生原表、上传记录、运行日志和凭据。匹配会话在内存中隔离，闲置24小时失效，重启清空。

## 备份与迁移

偏好设置中的“导出数据”下载当前教师库 `.db` 文件，包含公开种子记录和人工维护、增量更新的教师资料。“导入数据”选择此前导出的 `.db`，验证后替换当前教师库，原库自动备份。这两个按钮不打包学生原表、匹配结果或偏好设置。

需要保存全部文件时，先使用“退出程序”停止共享后台，再复制整个数据目录。默认位置为 `%USERPROFILE%\JunZhenMatch`，其中包括教师库、导出结果、自动备份及日志。不要在后台运行期间剪切数据库文件。

移动到新位置后，重新启动程序，在偏好设置选择新目录并保存：目标已有兼容教师库时使用该库，空目录则迁移当前数据并保留原位置副本。如果整个默认目录已被移走，程序会先创建新的默认目录，随后选择移走后的原目录即可恢复原有教师库和文件。首次默认目录中的 `preferences.json` 负责记住选定位置，后续不要单独删除它。

每次导出匹配结果也会保存到数据目录的 `exports`；上传原表仅用于当次解析，不保存到数据目录。两版使用同一数据目录时共用后台和教师库；关闭界面不会停止服务，需点击右上角签名退出贴纸。

## 调整背景和动画

源码运行时，修改 `src/junzheng_match/web/theme.css` 中“可调视觉参数”下的变量，保存后刷新页面即可；EXE和MSI中的资源需重新编译后生效：

| 变量 | 当前值 | 作用 |
|---|---|---|
| `--scene-top` | `160px` | 背景顶部位置，减小即上移 |
| `--scene-opacity` | `.60` | 背景不透明度，越大越清楚 |
| `--scene-top-fade` | `7%` | 顶部渐隐长度，越小过渡越短；左右和底部不渐隐 |
| `--scene-image-scale` | `1` | 铺满后的缩放比例，`1.05` 表示再放大5% |
| `--sticker-opacity` | `1` | 左右小人完全不透明，不影响退出贴纸 |
| `--tab-slide-duration` | `260ms` | 顶部与数据库选择条的滑动时长 |

背景采用 `cover` 铺满左右边缘，保持比例，窗口比例变化时会裁去少量画面。退出贴纸不使用整块悬浮阴影；键盘聚焦时仍保留提示边框。选择条遵循系统减少动画设置。
